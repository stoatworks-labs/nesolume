*nesolume — retro console video hardware (raster/palette/attribute cells + glitches), FFGL + OFX; PUBLIC MIT, v0.1.0 RELEASED 2026-08-04 with demo + website + guide; never loaded into Resolume*

**nesolume** (started 2026-08-03) — retro console video hardware as an FFGL
effect for Resolume: downsample to a console raster, quantise through its
palette with attribute cells enforced, plus scroll-register distortion and
palette-legal glitches. `~/Projects/nesolume`, **PUBLIC MIT**,
github.com/stoatworks-labs/nesolume, effect ID `NE01`. **v0.1.0 released
2026-08-04** by the tag-triggered CI (dmg + setup.exe + FFGL zips + OFX zips,
Windows compiled first try — vcpkg.json was in place from day one).

**The two invariants that ARE the plugin:** corruption happens before
quantisation so no glitch can leave the palette (`tools/verify.py` checks
every pixel against the master palettes with corruption at full); displacement
moves whole texels and wraps like a scroll register, never touching colour.

Nine consoles in `source/Consoles.cpp` — a new console is one table row.
Fixed palettes (GB greens, NES 2C02 64-entry, Spectrum 15, C64 Pepto) vs RGB
DAC depths (SMS 2, MD 3, SNES/PSX 5, Custom 1–8 from slider). Raster is
height-only; width follows composition aspect (square pixels — deliberate).
Clash model: pixel keeps its luma, chroma pulled to the attribute cell's mean.
Glitch clock = Rate × 18 Hz re-rolls; Rate 0 pins the key → a crashed still.

Verified via `netest`: palette legality, 15-param sweep, preset 8
byte-identical to hand-set, deterministic, 0.17/0.56 ms per frame at
1080p/4K (M4 Max). **ffgltest passes** — the About TEXT param needed the
SetTextParameter override ([ffgl instantiate sweep trap](https://github.com/stoatworks-labs/fleet-notes/blob/main/notes/reference_ffgl_instantiate_sweep_trap.md); found
that old-cathode HEAD has the same latent bug, flagged as a spawn task).
**OFX port done** (`source/ofx/NESolumeOFX.cpp`, low-res chain precomputed
once per render, only display in the threaded loop): ofxprobe render, Mix=0
identity exact, preset byte-identical, output palette-legal (ofxprobe's BMP
has a 4px divider column at w/2 — not plugin output).
